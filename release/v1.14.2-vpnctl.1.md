# v1.14.2-vpnctl.1

The first release on the sing-box v1.14.2 core. It replaces v1.14.0-vpnctl.5.

## Changed

- Core: official sing-box v1.14.2 and wireguard-go v0.0.7, with the macOS fix for a connected socket that stops receiving.
- AmneziaWG: `rekey_after_time` now works. Before, a configuration that set it was rejected by the device.
- AmneziaWG: a handshake is no longer mistaken for transport data when the prefixes differ and the H4 range is wide.
- AmneziaWG: `jc` is limited to 128 and `jmax` to 65507; the range `0-4294967295` for `rekey_after_time` is rejected.
- macOS: reserved bytes are cleared on a connected socket and per source endpoint; an empty junk packet no longer crashes the process.
- XHTTP: an expired read deadline always ends the read; a superseded deadline timer is ignored; closing a connection locally no longer counts as a server failure; a failed upload in packet-up mode ends the connection; a query parameter with an encoded key is replaced; a custom session alphabet is checked for path-unsafe characters.

Everything from v1.14.0-vpnctl.4 and v1.14.0-vpnctl.5 is included.

## Compatibility

- A configuration with `jc` above 128, `jmax` above 65507 or `rekey_after_time` set to `0-4294967295` is now rejected at start.
- XHTTP speaks HTTP/2 only, as before; earlier documentation wrongly mentioned HTTP/1.1.

## Verified

- The whole upstream test suite, the fork's tests with the race detector, cross-builds for all six targets and the Android library, on the released commit.
- AmneziaWG handshake and data transfer between two instances of this engine, plain 2.0 and every 3.1 extension alone and together, on Linux, macOS and Windows runners.

## Not verified

- An Android device, the official AmneziaWG implementation as the other side, a real Xray server.

## Known issues

- The dependencies pinned by sing-box v1.14.2 include grpc v1.79.1 and x/crypto v0.54.0, which have published vulnerabilities in the gRPC server and the SSH package. Keep the V2Ray API and other gRPC listeners on a local address.
- XHTTP has no write deadline in packet-up mode.
