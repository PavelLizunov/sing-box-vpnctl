# v1.14.2-vpnctl.2

A dependency update on top of v1.14.2-vpnctl.1. No change in behaviour is intended.

## Changed

- `google.golang.org/grpc` v1.79.1 -> v1.83.2 and `golang.org/x/crypto` v0.54.0 -> v0.56.0. This closes the seven published vulnerabilities the scanner reported as reachable: four in the gRPC server (a crash on a request without an authority, memory exhaustion through fragmented HTTP/2 data frames, an authorization bypass through a path without a leading slash, and issues in the RBAC engine and HTTP/2 server) and three in the SSH package.
- These two updates pull newer `golang.org/x/net`, `x/text`, `x/mod` and `go-jose` with them, and raise the Go version the module asks for to 1.26.

Upstream sing-box v1.14.2 still pins the older versions, so `go.mod` and `go.sum` differ from upstream here on purpose. The difference goes away when upstream updates these modules.

## Compatibility

- Building from source needs Go 1.26 or newer.

## Verified

- The whole upstream test suite, the fork's tests with the race detector, cross-builds for all six targets, the embedded WireGuard tests on macOS and Windows and the Android library, on the released commit.
- The vulnerability scan reports no reachable vulnerability.

## Not verified

- An Android device, the official AmneziaWG implementation as the other side, a real Xray server.
