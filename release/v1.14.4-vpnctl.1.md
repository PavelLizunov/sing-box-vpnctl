# 1.14.4-vpnctl.1 candidate

This branch is a release candidate, not a published release or a deployment.

## Changes

- Merge official sing-box `v1.14.4` (`c005f35300ce76427dc285481ec5695f5b179cd2`) from the corrected `1.14.2-vpnctl.2` fork line. Preserve the AWG 2.0/3.1 wire framing, protected-header classification, reserved-byte handling and XHTTP deadline/failure corrections.
- Port the embedded SagerNet WireGuard fixes through `e4d85ef2ed38`: complete IPv6 destination copies after IPv4 pool reuse, count suspend time when checking key/handshake age, and wait for resume outside timer locks while rejecting obsolete timer callbacks. Keep the fork's configurable AWG rekey threshold.
- Update `golang.org/x/net` to `v0.62.0` and its minimum dependency set to address GO-2026-6860, GO-2026-6617, GO-2026-6612, GO-2026-6611, GO-2026-6610 and GO-2026-6603. Retain the newer gRPC security pin.
- Pin the fork's CI, Verify and release toolchains to Go `1.26.10`, fixing GO-2026-6809 and preventing setup-go from silently selecting a cached `1.26.9` for `1.26.x`.
- Restore the fork boundary: keep reusable AWG probes explicitly owned; retain historical reports in Git rather than the source tree. The boundary checker is unchanged. Module hook budgets match the reviewed security dependency delta.
- Extend the on-demand Verify workflow with the boundary check and a pinned official AmneziaWG peer, testing synthetic TCP/UDP traffic in a fresh network namespace. Existing native Windows/macOS, six-target cross-build, Android library and vulnerability jobs remain enabled.

## Acceptance and limits

Use the Verify run for the exact candidate commit, not results from an earlier release. Local Linux testing excludes the privileged `TestUnshareNamespace` when the host denies namespaces; the GitHub suite runs it with sudo. Candidate artifacts carry a `-candidate` version suffix until a release is explicitly approved.

XHTTP remains client-only HTTP/2 (`h2` or `h2c`), without HTTP/1.1, HTTP/3 or separate download settings. Official AWG interop uses synthetic UAPI configuration and isolated peers, not production configurations or a native `.conf` importer. Building Android AARs is not Android-device testing. Automated age tests do not simulate physical system suspend.
